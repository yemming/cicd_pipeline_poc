## 三、核心錯誤說明

本次修正針對兩個根本性的邏輯錯誤，以及 5 支受連帶影響的頁面。

---

### 核心錯誤一：PDI 工單觸發時機錯誤

**影響頁面：** `RS05_交車管理_v1.html`

**舊版錯誤：**
RS05 STEP 1 標題為「PDI 整備觸發」，頁面內有「建立 PDI 工單並通知 SA」按鈕。
這代表業務在**交車當天**才建立 PDI 工單，等於「車輛賣出後才做整備」，邏輯完全錯誤。

**正確邏輯：**
PDI 工單必須在**車輛到港入庫時**（INV02 到港確認頁面）自動觸發。
技師完成 PDI 並主管核准後，車輛狀態才變為「可銷售（AVAILABLE）」。
業務到了 RS05 交車時，PDI 早已完成，只需「確認 PDI 已完成」並附上副本。

**本次修正內容：**
- STEP 1 標題改為「PDI 完成確認」
- 移除「建立 PDI 工單」按鈕
- 改為三種狀態確認卡：PDI已完成（綠）/ PDI進行中（琥珀）/ PDI未完成（紅）
- PDI 未完成時，下一步按鈕鎖住，無法進行交車
- 新增說明面板，說明正確 PDI 流程

---

### 核心錯誤二：中古車收購確認後無任何系統動作

**影響頁面：** `RS06_中古車評估鑑價_v2.html`

**舊版錯誤：**
RS06 Tab4 的「收購決策」下拉選單只是普通 `<select>`，沒有 `value` 屬性。
確認按鈕點擊後只顯示一個 Toast 提示，沒有觸發任何後續流程。
收購完成後，中古車車輛主檔不會被建立，整備工單不會被觸發。

**正確邏輯：**
確認收購後，系統應自動建立中古車車輛主檔，並觸發整備工單（PD-UC），費用計入整車成本。

**本次修正內容：**
- 收購決策下拉改為有 value 的四個選項（BUY_NORMAL / BUY_COND / BUY_MGR / NO_BUY）
- 依選擇顯示對應說明卡與按鈕
- 確認收購後顯示成功結果卡，含中古車主檔號與整備工單號
- 後端 API 串接點以程式碼註解標示

---

### 連帶修正一：RS03A 新車庫存看板

**影響頁面：** `RS03A_新車庫存看板_v1.html`

**舊版問題：**
- 只有三種狀態：現車可售 / 已保留 / 訂車中
- 缺少「待PDI（PENDING_PDI）」狀態，到港後的車輛無法正確顯示
- 業務在 PDI 未完成時仍可對該車報價，邏輯錯誤
- 整車成本欄位缺失

**本次修正內容：**
- 新增「待PDI」狀態（紫色），連結 PDI 工單進度
- 「待PDI」車輛的報價按鈕鎖定，無法配車
- 卡片底部新增 PDI 進度條（綠色，顯示完成百分比）
- 新增「整車成本」與「毛利空間」欄位（PDI完成後顯示）
- 新增到港入口橫幅，引導前往 INV02 到港確認
- KPI 改為動態計算

---

### 連帶修正二：RS03B 中古車庫存看板

**影響頁面：** `RS03B_中古車庫存看板_v1.html`

**舊版問題：**
- 無中古車入庫入口，業務不知道從哪裡新增中古車
- 缺少車輛來源類型（置換 / 直購）欄位
- 整備成本未顯示，整車成本不透明
- 待整備車輛無整備工單連結

**本次修正內容：**
- 新增入庫入口橫幅（置換→RS06 / 直購→RS_INV05）
- 每台車輛新增來源 badge（🔄置換 / 🛒直購）
- Filter 新增來源類型篩選
- 卡片顯示：收購成本 / 整備成本（+N）/ 整車成本合計
- 待整備車輛顯示整備工單號，動作按鈕改為「整備工單」
- KPI 改為動態計算

---

### 連帶修正三：02 正式工單 RO

**影響頁面：** `02_正式工單RO.html`

**舊版問題：**
- 業務類型只有 5 種（MN / RP / WC / AC / OT），缺少 PD（PDI整備）
- 導致 PDI 工單無法正確分類，費用歸屬無法與整車成本連動

**本次修正內容：**
- 新增第 6 種業務類型：PD（PDI整備），綠色視覺
- 選 PD 時，付款性質自動鎖定為 IN（內部結算），其他選項隱藏
- 顯示 PD 費用說明卡（整車成本 / 車主應付 NT$0）
- 確認按鈕變綠色，Toast 說明費用計入整車成本

---

### 連帶修正四：09 人車檔案

**影響頁面：** `09_人車檔案.html`

**舊版問題：**
- 工單歷史表格無「類型」欄，PD 工單與一般工單外觀相同
- PD 工單費用欄顯示格式與一般工單相同，沒有說明費用歸屬

**本次修正內容：**
- 工單歷史表格新增「類型」欄，顯示彩色 badge（PD=紫色 / WC=綠色 / RP=琥珀色 / AC=紅色 / MN=深藍色）
- PD 工單費用欄顯示綠色「整車成本」標籤，不顯示客付金額格式
- 新增 bpurple CSS 樣式

---

### 連帶修正五：10 工單查詢

**影響頁面：** `10_工單查詢.html`

**舊版問題：**
- 假資料只有 PD-IN（新車PDI）一筆，且車主名稱為客戶姓名（錯誤）
- 缺少 PD-UC（中古車整備）類型的範例資料
- PD 工單金額欄顯示格式與一般工單相同

**本次修正內容：**
- PD-IN 車主欄改為「[內部] 海德生」，正確反映 PDI 為內部作業
- 新增 PD-UC-260502-001（中古車整備）假資料一筆
- PD 工單金額欄顯示綠色「整車成本」標籤

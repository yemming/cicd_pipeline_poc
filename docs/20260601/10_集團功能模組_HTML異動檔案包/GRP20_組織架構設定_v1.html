⚠️ 上線前必須完成 — 組織架構與權限設定是整個系統的安全基礎
1. 組織架構設定（此頁面）必須先完成，才能進行其他任何設定。
org_mode值（3=三層/4=四層）儲存於 system_settings 表，影響全系統的組織樹顯示與報表篩選器。

2. Supabase Row Level Security（RLS）必須依此頁面設定的角色權限矩陣配置。
若未設定RLS，任何角色都能看到所有門店的敏感資料（含其他門店的業績、客戶資料、財務數字），嚴重違反數據安全原則。

3. 角色與頁面存取對應關係：
集團總經理/品牌運營協理 → GRP01-GRP20全部可看（唯讀）
通路管理經理 → GRP03/GRP07/GRP09/GRP13/GRP14
門店店長 → RS_M/CRM07（本店限定）
SA/業務員 → 售後/銷售模組（本店本人限定）

後端串接點：POST /api/org-nodes　｜　PUT /api/role-permissions　｜　Supabase：ALTER POLICY

### 1. `02_正式工單RO.html` 🔄 替換

**目錄位置：** `03_售後修護 / 01_工單主流程 / 02_正式工單RO.html`
**操作類型：** 🔄 完整替換

**修改原因：**
原版只有業務類型前綴碼選擇與「確認」Toast，缺少：
- 工單優先級（緊急客戶今日必須取車，主管看不到）
- 施工進度條（SA/主管不知道工單目前在哪個階段）
- 返工偵測（RP-FR返工工單無自動識別，可能重複向客戶收費）
- 保固期限驗證（WC工單可能在車輛已過保後開立）
- PD業務類型（PDI整備工單無法正確開立）

**新增功能：**

#### 1-1. PD 業務類型 + IN 付款性質（➕插入）
```
插入位置：業務類型選擇器中，OT 選項之後
新增選項：PD（PDI整備）→ 選擇後付款性質自動鎖定為 IN（內部結算）
邏輯：PD-IN 為唯一合法組合；PD-CP / PD-WR / PD-FR 均顯示錯誤
```
🔗 後端：`POST /api/workorders`（業務類型欄位新增 PD 值）

#### 1-2. 工單優先級選擇（➕插入）
```
插入位置：業務類型選擇器之後、確認按鈕之前
三個選項：🔴緊急（今日完成）/ 🟡一般 / 🟢彈性
選擇後寫入工單 priority 欄位
派工看板（07）依此欄位排序，緊急工單置頂紅色顯示
```
🔗 後端：`POST /api/workorders`（新增 priority 欄位）；`PATCH /api/workorders/{id}/priority`

#### 1-3. 施工進度條（➕插入）
```
插入位置：優先級選擇之後、確認按鈕之前
六個狀態：待派工 → 施工中 → 追加待確認 → 竣工複檢 → 待結帳 → 已關閉
各狀態旁顯示「通知車主」按鈕（📱LINE / 💬簡訊 / 📞電話）
⚠️ 重要：通知為 SA 人工決定發送，系統不自動外發
```
🔗 後端：`PATCH /api/workorders/{id}/status`

#### 1-4. 返工工單偵測（➕插入）
```
插入位置：進度條之後、確認按鈕之前（條件顯示）
觸發條件：選擇 RP 業務類型時，後端比對此車牌過去 30 天是否有相同類型工單
顯示橫幅：「此車輛於 X 天前進行過相同維修，是否開立 RP-FR 返工工單？」
選擇確認返工：付款性質自動改為 FR（本店承擔），不向客戶收費
```
⚠️ 測試前必須：返工未偵測將導致客戶重複付費糾紛
🔗 後端：`POST /api/workorders` 前查詢 `GET /api/workorders?vehicle_id={id}&type=RP&days=30`

#### 1-5. 保固期限驗證（➕插入）
```
插入位置：進度條之後、確認按鈕之前（條件顯示）
觸發條件：選擇 WC 業務類型時自動驗證
在保固期內：顯示綠色確認橫幅
已過保固：顯示紅色警示，需主管授權才可繼續
```
🔗 後端：`GET /api/vehicles/{id}/warranty-status`；`POST /api/workorders/warranty-auth-request`

### 8. `04B_快速報價查詢_v1.html` 🆕 新增頁面

**目錄位置：** `03_售後修護 / 01_工單主流程 / 04B_快速報價查詢_v1.html`
**操作類型：** 🆕 全新頁面，放入 01_工單主流程 目錄（與 04_預檢單系列並列）

**新增原因：**
SA 接待時需要即時查詢保養套餐、單項零件價格、工時費率並當場報價。若塞在預檢單 Tab2 側邊欄，平板操作空間不足，且查詢完需要一鍵帶入預檢單，需要獨立頁面承載完整流程。

**功能說明：**

#### Tab A：保養套餐查詢
```
- 帶入車型與里程（從 04_預檢單_RO串接 Tab2 點擊進入，自動帶入）
- 系統依里程自動建議對應套餐
- 套餐明細：工項清單、零件清單、料號、庫存狀態（三色）、費用
- 缺料提示：顯示跨店庫存與調撥時間
- 費用彙總：工資費 + 零件費 + 總計

三種結果按鈕（核心功能）：
  ✅ 車主同意 → 報價資料帶入 04_預檢單_RO串接 Tab4，跳回預檢單繼續流程
  ⏸ 暫存 → 暫存至此工單記錄，預檢單 Tab4 顯示「待車主確認」
  ❌ 拒絕 → 填寫拒絕原因，寫入人車檔案「待處理項目」，下次回廠自動提醒 SA
```
🔗 後端：`GET /api/service-packages?vehicle_model=X&mileage=X`；`POST /api/quotes/{id}/apply-to-inspection`；`POST /api/vehicles/{id}/pending-items`

#### Tab B：零件快查
```
- 依車型 + 年份篩選適配零件清單
- 輸入零件名稱/料號即時查詢庫存狀態與售價
- 缺料時顯示「查跨店庫存」
- 查到的零件可「加入報價」，累計後一鍵「帶入預檢單 Tab4」
```
🔗 後端：`GET /api/parts?vehicle_model=X&keyword=X`；`GET /api/inventory?sku=X&all_stores=true`

#### Tab C：工時費率
```
- 顯示各業務類型（MN/RP/WC/AC/Desmo）的工時費率（NT$/LU）
- DUCATI：全球統一標準工時，費率由門店設定
- Indian：工時與費率均可自訂
- 快速計算器：輸入工時（LU）自動計算工資費
- 常用工項工時參考表（可直接加入報價）
- 費率資料來源：07B_服務套餐與費率設定
```
🔗 後端：`GET /api/labor-rates?type=MN`

### 9. `07B_服務套餐與費率設定_v1.html` 🆕 新增頁面

**目錄位置：** `03_售後修護 / 03_車間管理 / 07B_服務套餐與費率設定_v1.html`
**操作類型：** 🆕 全新頁面，放入 03_車間管理 目錄（與 07_售後管理模組並列）

**新增原因：**
系統原本完全無服務套餐主檔設定功能。SA 接待時只能憑記憶或查紙本逐項手填，無法標準化，也無法設計門店促銷套餐。此頁面為主管後台設定頁，與 SA 的日常操作頁面分開管理。

**功能說明：**

#### Tab A：服務套餐主檔
```
三類套餐：
  1. 原廠標準套餐（6000km / 10000km / 20000km）：含工項清單、零件料號、標準工時、建議售價
  2. 門店自訂套餐（夏季健檢 / 環島前安檢等）：可設定有效期
  3. 限時促銷套餐：有效期到期後系統自動停用，04B 查詢頁即時移除

套餐管理：新增 / 編輯 / 停用
停用效果：04B_快速報價查詢即時不再顯示此套餐（SA 無法查到已停用套餐）
```
🔗 後端：`GET/POST /api/service-packages`；`PATCH /api/service-packages/{id}/status`

#### Tab B：標準工時費率表
```
DUCATI 費率表：MN/RP/WC/AC/PD/Desmo 各業務類型的工時費率（NT$/LU）
```

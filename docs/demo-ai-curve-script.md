# AI Curve Demo 練習腳本

> 用途：你跟潛在客戶 demo 時、自己用手機照唸的劇本。
> 唸的時候稍微帶口語停頓 / 想一想的語氣、不要像背書，AI 抽得會更像真實接待。
> 全長 30-40 秒、剛好夠 AI 抽出 6-7 個欄位、留 1-2 個空、看起來「優化空間還很大」。

---

## 🎬 主推腳本 A — 換車老客戶（自然版）

> 場景：業務在展廳接待客戶、用手機開 AI Curve 邊聊邊錄。

```
業務：先生你好，第一次來嗎？

客戶：對啊，是朋友介紹的，他上次來看過 Diavel V4。
    我自己現在騎 ER-6n、騎了五年想換大一點的。

業務：那您比較喜歡街車還是 cruiser？

客戶：我比較想看 Diavel V4，外型蠻喜歡的。
    不過我朋友最近也在比 Honda CB1000R、
    叫我也順便看一下。

業務：預算大概抓多少？

客戶：100 萬上下吧，半年內買應該 OK，
    不用急著現在下訂。

業務：那我們下週五展廳有試駕活動，
    要不要先約一個時間？

客戶：好啊，5 月 30 號早上 10 點可以嗎？

業務：可以可以、我幫您記下來。
```

### 預期 AI 抽出（8 欄裡會抓 6-7 個）

| 欄位 | 預期值 | confidence |
|---|---|---|
| customer_summary | 客戶想換車、目前騎 ER-6n、對 Diavel V4 有興趣、朋友推薦 CB1000R 做比較 | 90%+ |
| intent_level | **4**（半年內買、已約試駕） | 80% |
| purchase_timing | **6m** | 90%+ |
| intended_models | `["Diavel V4"]` 或 `["Diavel V4", "CB1000R"]` | 80% |
| competitor_brand | **Honda** | 80%（CB1000R 是真競品） |
| budget_range | **100 萬上下** | 90% |
| arrival_source | **朋友介紹** | 90%+ |
| followup_date | **2026-05-30** 或 **2024-05-30**（年份可能 hallucinate） | 80% |

⚠️ **AI 可能搞錯的點**（demo 時順便講「這就是業務要 review 的地方」）：
- followup_date 可能填 2024-05-30（沒 currentDate context）
- intended_models 可能漏掉 CB1000R（因為它是被「比較」的車不是「想買的」）

## 🎬 備用腳本 B — 純探詢客戶（簡短版、適合 demo 給沒耐心的客戶）

> 全長 25 秒、AI 會抽到 4-5 欄、留更多空白給「人工補」。

```
業務：歡迎光臨，今天看什麼車？

客戶：嗨，網路上看到 Scrambler 1100、
    想說來看一下實車。

業務：您是想入手嗎？

客戶：嗯⋯ 還在想啦，可能明年吧。
    現在主要先比較幾個品牌、看 KTM 也有 Duke 系列。

業務：那我留個聯絡方式、
    有新車到再通知您？

客戶：好啊，謝謝。
```

### 預期 AI 抽出

| 欄位 | 預期值 |
|---|---|
| customer_summary | 客戶看到 Scrambler 1100 想來看實車、明年再買、比較 KTM Duke |
| intent_level | **2**（明年才買、純比較） |
| purchase_timing | **explore** |
| intended_models | `["Scrambler 1100"]` |
| competitor_brand | **KTM** |
| budget_range | — （沒提到、空） |
| arrival_source | **網路搜尋** |
| followup_date | — （沒提到、空） |

## 💡 Demo 時的話術提示

開場：
> 「我們現在在展廳接待客戶、業務只要按一下這顆紅色按鈕、開始錄音、聊就好。」

按完錄音後等 AI：
> 「Gemini 2.5 大概 5-30 秒生成這 8 個欄位、不會干擾接待過程。」

看到結果跳出來：
> 「你看、客戶剛才提到的 Diavel V4、預算 100 萬、半年內買、朋友介紹來的、
>  全部都自動填好了。每一欄都有 confidence 分數、業務 review 一下勾接受就行。」

指著留空的 4 個業務手填欄位（客戶姓名 / 電話 / 身份 / 觀察標籤）：
> 「客戶姓名、電話這種敏感資訊、AI 不直接填、業務確認後手動補。
>  觀察標籤這種主觀判斷、也是業務自己加。」

收尾：
> 「12 欄手卡、AI 幫你抓 8 欄、剩 4 欄業務確認就好。
>  以前一張手卡寫 5 分鐘、現在 30 秒。」

## 🛠️ 練習建議

1. **第一次練習**：拿著腳本照唸一次、看 AI 抽得準不準
2. **第二次練習**：把劇本記住、用自然語氣講、加一些口語停頓
3. **第三次練習**：閉上眼睛、模擬「正在接待客戶」、AI 抽出來才像實戰
4. **正式 demo 前**：在現場錄一段「環境噪音」測準度（展廳冷氣聲 / 引擎聲）

---

## ⚠️ 已知會踩雷的地方（demo 時主動講出來反而加分）

1. **年份 hallucination** — 客戶說「5月30」、AI 可能填 2024-05-30 而不是 2026
   - 話術：「這個小問題我們之後加一行 prompt 就能修、demo 我先示範架構」

2. **競品分類** — 客戶說「朋友推薦 Indian Sport Chief」、AI 可能把 Indian 標成 competitor
   - 但因為 Indian 是我們經銷的，這次 prompt 已經教 AI 認得了、所以照本宣科應該沒事
   - 話術：「prompt 裡有教 AI 認 Ducati / Indian 是我們自己的品牌」

3. **「下週五」轉「下次五」** — 中文諧音 / 業務話術重的話容易聽錯
   - 話術：「轉錄 95% 的時候、剩 5% 的雜訊靠業務 review 補上」

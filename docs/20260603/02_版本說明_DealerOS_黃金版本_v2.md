## 給 Partner AI Agent 的重要說明

### ⚠️ 本版本與前版的三個差異

**1. 三支全新頁面（nav_nodes 尚未登記，需要新增）**

| 檔名 | 功能 | 應放目錄位置 |
|------|------|------------|
| `04B_快速報價查詢_v1.html` | SA快速查詢套餐/零件報價，三種結果（同意/暫存/拒絕） | ③售後修護 → 01_工單主流程 → 開立工單RO 之後 |
| `07B_服務套餐與費率設定_v1.html` | 服務套餐主檔管理 + 工時費率表（DUCATI/Indian分開） | ③售後修護 → 03_車間管理 → 服務套餐設定 |
| `10B_告警儀表板_v1.html` | 庫存健康每日總覽：5個告警Tab + PDC截單倒計時 | ④庫存管理 → 06_預警告警 → 告警儀表板 |

**2. 21支修改頁面（直接覆蓋即可）**

| 模組 | 修改支數 | 主要修改重點 |
|------|---------|------------|
| 售後修護 | 7支 | PD業務類型、電子簽名、Quick Quote入口、返工偵測、5節點通知 |
| 庫存管理 | 7支 | 再訂購點計算、PDC倒計時、Camera掃碼、供應商績效看板 |
| 集團管理 | 7支 | 下鑽跳轉、Pace配速計算器、alert→Toast、RLS警示橫幅 |

**3. 版本號規則（供後續維護參考）**

```
v1.0 = 2026-05-29 基底版（127支）
v2.0 = 2026-06-02 本版（130支）= v1.0 + 06/01異動包
```

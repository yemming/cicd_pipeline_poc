⚙️ 參數設定頁
以下所有下拉選單、代碼清單、數值閾值，均可由主管自行新增、修改、刪除、排序。
灰色 系統預設 項目為系統內建，刪除後可從「還原預設」回復；綠色 自訂 為店內新增項目。
📋 UI 規範說明（開發用）
  • 清單型參數：可拖曳排序、新增、修改、刪除，適用線索來源、購買方式、競品清單等
  • 數值型參數：直接輸入數字，有預設值與還原按鈕，適用跟進天數、閾值設定等
  • 開關型參數：On/Off 切換，適用功能啟用/停用
  • 必填項目：以 必填 標示，不可刪除
  • 所有變更須點擊右上角「儲存所有設定」才正式生效，未儲存前顯示暫存狀態

## 編排策略（主 Agent = 我）

- **我（主 Agent）**負責協調、序列化共用檔/DDL、守閘門；**工作包派 sub-agent** 下去做。
- **workflow fan-out** 用在「可平行又獨立」的步驟：多支 HTML 巡檢比對、多支頁面升級、多份 Word 回寫、多場景 Playwright。
- **效能護欄**：同時 **≤ 3 agent**；改同一檔/同一張表的工作**序列化**（避免衝突）；只有並行改不同檔才用 worktree isolation。
- **每個工作包交付即回報 + 打勾**，不一次悶頭跑完。

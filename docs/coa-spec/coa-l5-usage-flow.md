# 會計科目 L5 借貸用法流程表（221 個 postable 科目）

**版本**: v1 · 2026-05-10
**對映**: DealerOS COA v2.0 / 機車經銷商業態
**用途**: 給每個 L5 入帳科目寫清楚「什麼業務情境會用到、借方/貸方對應什麼」，作為傳票切票時的查表手冊，也是日後 `transaction_types` template 的設計依據

---

## 怎麼讀這張表

```
| 代碼 | 名稱 | D 借方場景（科目餘額增加）| C 貸方場景（科目餘額減少）| 常見對方科目 | 必填維度 |
```

- **正常餘額（normal_balance）**：D=借餘 / C=貸餘
- **D 場景**：什麼業務情境會「借記」這個科目（讓餘額增加 if 借餘 / 減少 if 貸餘）
- **C 場景**：什麼業務情境會「貸記」這個科目（反向）
- **常見對方**：通常哪個科目會跟它配對（D側↔C側）
- **必填維度**：過帳前 DB trigger 會檢查的維度（缺了就不能 post）

> ⚠️ 分錄要平衡 = 借方總和 = 貸方總和；不是「借方 = 餘額」喔。
